# Tienda de Uniformes Médicos - Gestión de Pedidos 🏥🧵

Sistema móvil de gestión de pedidos y confección optimizado para tiendas de uniformes médicos. Diseñado para ser ligero, táctil y fácil de desplegar.

## 🚀 Características
- **Mobile-First**: Interfaz táctil optimizada para teléfonos móviles (Tailwind CSS).
- **Catálogo Dinámico**: Gestión de modelos de uniformes desde el panel.
- **Flujo de Producción**: Seguimiento de estados (Pendiente, Listo, Entregado).
- **Integración WhatsApp**: Notificaciones directas a clientes con un solo clic.
- **Ficha de Taller**: Vista de alta visibilidad para el taller de costura/bordado.
- **Seguro y Ligero**: Sin dependencias externas, PHP Nativo y PDO.

## 🛠️ Instalación Local
1. Clonar el repositorio.
2. Importar el archivo `database.sql` en tu servidor MySQL.
3. Copiar `config.example.php` a `config.php`.
4. Editar `config.php` con tus credenciales de base de datos.
5. ¡Listo! Accede vía `localhost`.

## 🔒 Seguridad
El archivo `config.php` está ignorado por Git para proteger tus credenciales. Asegúrate de configurar siempre `config.php` basándote en la plantilla `config.example.php`.
